Schedules

These are kagent scheduled runs: kagent stores them and fires them itself, so they keep running when this page is closed, and they also appear under Schedules in the kagent UI. Each run wakes the dottie in a conversation of its own.

This dottie has long-term memory, and kagent 1.0.0 cannot run schedules for it: a scheduled run reaches the agent without a caller identity, which memory requires. Create a dottie without memory to schedule it.
